计算原理说明
BMR 基础代谢率 (Mifflin-St Jeor)
BMR = 10 x 体重(kg) + 6.25 x 身高(cm) - 5 x 年龄 + 常数
男性常数 +5，女性常数 -161
TDEE 每日总消耗
TDEE = BMR x 活动系数
活动系数根据运动频率在 1.15~1.60 之间
运动消耗 (MET 法)
热量 = MET值 x 体重(kg) x 时长(小时)
MET = 代谢当量，不同活动对应不同数值
