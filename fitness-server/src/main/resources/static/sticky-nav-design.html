固定顶部返回栏设计方案

参考 iOS 原生导航栏、微信小程序、Keep、支付宝等主流应用，为健身助手 App 设计统一的固定顶部导航栏方案，提升用户在滚动浏览时的操作效率与体验一致性。

📌

始终可达

导航栏固定在顶部，无论页面滚动多深，返回按钮始终触手可及，无需回滚到顶部。

🧊

毛玻璃质感

采用 backdrop-filter 模糊效果，滚动时内容透过导航栏若隐若现，兼顾美观与信息层次。

🎨

主题适配

每个页面模块保持各自的色彩主题（蓝/绿/橙/紫），导航栏背景色与页面主题色协调统一。

✨

滚动感知

滚动时导航栏自动增强背景不透明度和阴影，静止时保持透明轻盈，智能响应滚动状态。

对比效果 核心改进

左侧为当前实现 — 滚动后导航栏随内容消失；右侧为优化方案 — 导航栏始终固定在顶部，滚动时自动增强视觉效果。请滚动两个手机预览查看差异。

以下是统一的导航栏 CSS 方案，可直接应用到各页面的 .header / .nav-header 样式中。

/* 通用固定导航栏方案 — 适配所有子页面 */

.header {
  /* 核心固定定位 */
  position: sticky;
  top: 0;
  z-index: 100;

  /* 毛玻璃效果 */
  background: rgba(240, 249, 255, 0.72);  /* 蓝色主题 */
  backdrop-filter: blur(20px) saturate(1.8);
  -webkit-backdrop-filter: blur(20px) saturate(1.8);

  /* 边框与过渡 */
  border-bottom: 1px solid transparent;
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);

  /* 布局 */
  display: flex;
  align-items: center;
  gap: 16rpx;
  padding: 100rpx 30rpx 20rpx;  /* 100rpx 为状态栏安全距离 */
}

/* 滚动后增强效果（需 JS 配合） */
.header.scrolled {
  background: rgba(240, 249, 255, 0.92);
  border-bottom: 1px solid rgba(14, 165, 233, 0.12);
  box-shadow: 0 1px 12px rgba(14, 165, 233, 0.06);
}

/* 各主题色背景适配 */
.theme-blue   .header { background: rgba(240, 249, 255, 0.72); }
.theme-green  .header { background: rgba(240, 253, 244, 0.72); }
.theme-orange .header { background: rgba(255, 247, 237, 0.72); }
.theme-purple .header { background: rgba(250, 245, 255, 0.72); }
.theme-indigo .header { background: rgba(238, 242, 255, 0.72); }
.theme-teal   .header { background: rgba(240, 253, 250, 0.72); }
/* 滚动检测 JS（uni-app 页面中使用 onPageScroll） */

export default {
  data() {
    return {
      isScrolled: false
    }
  },
  onPageScroll(e) {
    this.isScrolled = e.scrollTop > 10
  }
}

<!-- 模板中绑定 class -->
<view class="header" :class="{ scrolled: isScrolled }">
